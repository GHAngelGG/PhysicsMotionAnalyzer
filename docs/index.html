Código QR

Escanea el QR con tu celular para abrir esta aplicación. Si la sirves en red local, ingresa la URL manualmente.

URL de destino
Cómo compartir en red local:
1. Abre una terminal en la carpeta web/
2. Ejecuta: python -m http.server 8080
3. Tu URL será: http://<tu-IP>:8080
4. Pégala arriba y genera el QR
